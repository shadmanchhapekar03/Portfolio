Projects

Things I’ve built.

Agents · Evaluation

Automated Document Extraction & Prompt Optimization

A LangGraph workflow (extract, evaluate, route, optimize) that pulls structured JSON from PDFs and PAN card images. Pydantic enforces the schema, and a target score with a retry limit keeps runs predictable and cost-bounded. Output is scored field by field against ground-truth JSON with Levenshtein similarity, and mismatches are used to rewrite the prompt and run again.
